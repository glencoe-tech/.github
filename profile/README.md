# Glencoe Technology

Engineering home for Glencoe Technology — products (Axentra, ScreenMind), client work, and the
infrastructure behind them.

**How we work:** every repo inherits the
[Engineering Quality Standard](../ENGINEERING-QUALITY-STANDARD.md) —
fail-closed CI, PRs not pushes, secrets never in repos, and **infrastructure exists only through
Terraform** (`glencoe-infra`, `axentra-infra`). See
[CONTRIBUTING](../CONTRIBUTING.md) before your first PR.
